## 配置客户端

官方使用文档提供 Phantom 安卓版、Mac 版和 Win 版教程；iOS 栏目列有 Nextin、Clash Lite 和 ClashMi，官网将前两项标为推荐。请按自己的平台阅读对应教程。核验日期：2026 年 10 月 28 日。

### 开始前准备

- 准备可登录的 Phantom 账户。
- 在控制台确认有可用订阅。
- 确认设备系统和版本，选择对应教程。

### 安装并导入订阅

1. 打开 [官方使用文档](https://pin.dianping.men/app/knowledge)，选择对应教程，例如 **Phantom(Win版)**。
2. 按教程下载并安装客户端。
3. 在客户端中按教程导入控制台提供的订阅。
4. 更新订阅，确认客户端已显示节点列表。

### 验证连接

1. 在客户端中选择一个“通用”节点（如果有）。
2. 按客户端说明启用代理连接。
3. 打开常用网站，检查能否访问。

**验证结果：** 常用网站能访问后，继续测试日常应用。报错或其他应用无法连接时，按 [连接排障指南](https://phantom-release.github.io/Phantom/network-troubleshooting.html)检查。

使用其他客户端时，先核对内核是否支持订阅中的协议。Mieru 是否可用取决于具体内核版本。

| 需求 | 建议检查 |
| --- | --- |
| 日常网页、AI 对话 | 连续使用常用网站，观察连接中断、登录和地区识别 |
| 视频 | 连续播放并拖动进度条，观察缓冲 |
| 下载 | 下载实际需要的文件，观察持续速度 |
| 手机流量 / 家庭宽带 | 分别测试同一节点 |
| IPv6 节点 | 用 [test-IPv6](https://test-ipv6.com/) 检查本机网络 |
| 出口与 DNS | 用 [IPLeak](https://ipleak.net/) 查看实际出口和 DNS |

## 排查连接问题

| 现象 | 排查顺序 |
| --- | --- |
| 节点全部超时 | 确认套餐有效，更新订阅，再换网络测试 |
| “流量”节点超时，“通用”可用 | 检查本机、路由器和运营商的 IPv6 支持 |
| 导入后缺少节点或提示未知协议 | 更新客户端与内核，检查是否支持 Mieru、TUIC、Hysteria2、VLESS |
| 浏览器能用，其他应用不能用 | 检查应用是否遵循系统代理；按客户端说明使用 TUN |
| 某个网站打不开 | 换节点后复测，检查规则是否让该网站经过代理 |
| 高峰期卡顿 | 在同一网络换地区或协议，对比持续使用体验 |

## 配置与传输安全

该历史配置中 TUIC 和 Hysteria2 均明确设置 `skip-cert-verify: false`，VLESS 均启用 TLS。代理会转发你的流量，HTTPS 负责加密浏览器与目标网站之间的内容；服务端仍可能看到目标地址、连接时间和流量大小。

订阅链接、节点密码、UUID 和账户信息应自行保管，不要放进公开仓库。
